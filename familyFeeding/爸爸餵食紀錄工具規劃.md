# 爸爸餵食紀錄工具規劃

這個工具讓三位家人共用同一份餵食紀錄。通常一天約四餐，有時只餵三餐；牛奶有高纖、補體素、雙卡、一般四種，種類與次數都可彈性調整。下一餐至少在上一餐餵完 3.5 小時後開始。打開手機就能知道上一餐何時餵完、餵了哪種牛奶、誰餵的，以及下一餐最早可開始時間和今天各種奶已餵幾次。建議做成可加入手機主畫面的共用網頁，方便三人隨時查看與記錄。

## 首頁

首頁只放最常需要看的資訊，字體及按鈕要大：

```text
爸爸餵食紀錄

最早可開始  14:30（上一餐 11:00 餵完）
上一餐    11:00 餵完 · 高纖 · 家人甲
狀態    目前沒有人正在餵

[ 我要餵這餐 ]
[ 補記上一餐 ]

今天已餵  1 餐
高纖 1 次 · 補體素 0 次 · 雙卡 0 次 · 一般 0 次
[ 查看歷史紀錄 ]
最後同步：13:52
```

畫面中的餵食時間只是示意。「最早可開始」代表上一餐餵完後滿 3.5 小時的時間，不代表必須準點餵，也不代表當天一定還要再餵一餐。實際餵食安排仍以家中的照護指示為準。

## 餵食流程

第一次使用時，每位家人選自己的名字，之後由手機記住。餵之前按「我要餵這餐」，從四種奶品中選一種；畫面同時顯示每種奶今天已餵幾次，讓家人自行判斷。工具記下實際開始時間，並向其他兩人顯示「某某正在餵」。餵完按「完成並儲存」，工具記下實際餵完時間；必要時可修正時間或加備註。一般情況只需選奶品、按開始、按完成。

如果尚未開始就取消，按「取消這次」。若餵食已開始但未完成，可標示「中止」，保留紀錄供家人確認；工具不把中止當成完整一餐。忘記當場記錄時，可按「補記上一餐」，選實際日期、時間、奶品及餵食人。歷史紀錄允許更正誤記，並留下修改人和修改時間。

## 下一餐與奶品怎麼算

工具以上一餐的實際餵完時間加上 3 小時 30 分，顯示「若要餵下一餐，最早可開始的時間」。若晚於這個時間餵，後續最早時間也隨新的實際餵完時間往後移，不要求家人固定準點。跨日也須遵守最少間隔。若有人在時間未到時嘗試開始，畫面明確提醒並要求家人確認實際安排，但紀錄功能仍可保留真實發生的餵食。工具不自行決定醫療上的份量或變更餵食安排。

首頁顯示今天總共已餵幾餐，以及高纖、補體素、雙卡、一般各餵幾次；尚未餵的奶品顯示 0 次。四種奶都可隨時選擇，同一種一天可選兩次，也可一整天不選。工具不把 0 次視為漏餵，不強制每種各一次，也不在第三或第四餐後自動結束當天。若短時間又選同一種，可提示家人核對，但不阻止記錄。

補記或更正後，工具按實際餵食時間重新排序、計算最早可開始時間和今日奶品次數；不能因為某筆較晚輸入，就把它當成最後餵的一餐。每日奶品次數按實際餵食日期歸屬，但跨日的第一餐仍須檢查與前一天最後一餐的間隔。如果餵食中止，下一餐需顯示「請家人確認」，不直接套用完整一餐的規則。

## 三人共用時的關鍵設計

- 三人讀寫同一份線上資料；每次準備餵前先更新最新狀態。
- 兩人同時按「我要餵這餐」時，只有一人能取得進行中狀態，另一人立即看到誰正在餵。
- 網路中斷時顯示「無法確認最新紀錄」及最後同步時間；未同步的紀錄不能顯示成已儲存。
- 儲存失敗重試不會重複新增同一餐；相近時間的重複紀錄會提示核對。
- 家庭連結要有基本存取保護，例如首次輸入家庭代碼並記住裝置。

## 第一版範圍與驗收

第一版包含共用首頁、三人身分選擇、開始與完成餵食、補記與更正、四種奶品按鈕、今日各品項次數、下一餐最早可開始時間，以及歷史紀錄。每筆紀錄至少保存開始與餵完的實際日期時間、奶品、餵食人、狀態和修改時間。到達最早可開始時間可在首頁提示；手機通知或 LINE 提醒可等第一版實際使用後再決定。

驗收時應確認：一人完成後另外兩人立即看見更新；兩人同時開始不會重複餵；補記較早的一餐不會算錯下一餐；更正奶品會重算今日進度；網路中斷或儲存重試時不會把未存的紀錄誤認成已完成。

目前已能明確規劃第一版：每天餐數與奶品分配彈性調整，最少間隔從上一餐實際餵完時間起算。家人每次看見最近紀錄、最早可開始時間和今天各奶品次數，再自行決定是否餵及選哪一種。
